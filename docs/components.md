# Базовые компоненты

Библиотека содержит базовые DOM-компоненты и интерактивный пример
ButtonInteractionDemo. API составных блоков и страницы описаны
в [game-shell.md](game-shell.md). Все файлы и истории лежат плоско
в корневой `components/`. Утилитарные классы не передаются снаружи.

## API

| Компонент | Назначение и публичный контракт |
| --- | --- |
| [Typography](../components/Typography.ts) | `text`, семантический `as`, `variant`, `tone`, идентификатор, доступное имя и live-режим. Создаёт текст через `textContent`, без разбора HTML. Размеры и интервалы заданы токенами; длинный текст переносится. |
| [Wrapper](../components/Wrapper.ts) | `children`, ограниченный семантический тег, flex/grid, направление, колонки, gap/padding/margin, выравнивание, ширина и предел колонки. Layout-значения поддерживают `base/sm/md/lg`, классы берутся из полных статических таблиц. `dir` не передаётся в DOM. Flex принимает `dir`, grid — `columns`; несовместимые сочетания запрещены типами. |
| [Button](../components/Button.ts) | Строковая `label`, `variant`, `size`, `disabled`, `fullWidth`, `onClick`, идентификатор и атрибуты доступности. Нативный `button` с `type="button"`; подпись — Typography. Возвращаемый элемент поддерживает `setLabel(text)` без замены кнопки. |
| [Surface](../components/Surface.ts) | `children`, `variant`, `size`, `fullWidth`, семантический тег, идентификатор и доступное имя. Владеет фоном, рамкой, радиусом и внутренним отступом панели. |
| [BoardCell](../components/BoardCell.ts) | Пустая клетка либо `active/locked` с обязательным типом фигуры; четыре размерных режима, включая fluid. `decorative` скрывает клетку от accessibility tree, иначе доступно имя; `data-state` и `data-piece` отражают данные. |
| [ButtonInteractionDemo](../components/ButtonInteractionDemo.ts) | Пример библиотеки: композиция кнопки и live-счётчика; локальное состояние каждого экземпляра. Принимает содержимое и семантические параметры Button без внешнего onClick. |
| [KeyHint](../components/KeyHint.ts) | `key`: обозначение клавиши. Нативный `kbd`, внутри Typography. Размер зависит от содержимого, длинные обозначения переносятся. |

`style`, `className`, `class`, `css`, `sx`, объекты overrides и произвольные CSS
не являются частью API. Возвращённый DOM-элемент можно вставлять в документ
и использовать для фокуса, но потребитель не должен изменять его оформление.
Контент `children` — готовые элементы компонентов; видимые текстовые узлы
создаются через Typography. Обычная композиция не используется для overrides.

Пример композиции существующих примитивов:

```ts
const panel = Surface({
  children: [Wrapper({
    gap: 'md',
    children: [
      Typography({ as: 'h2', variant: 'heading', text: 'Партия' }),
      Button({ label: 'Начать игру', onClick: onStart }),
    ],
  })],
});
```

`theme.css` — общий Tailwind entry point и токены. Он не стилизует компоненты
глобальными или родительскими селекторами. Конфигурация приложения и Storybook
использует тот же Vite-плагин и тот же файл темы.

## Storybook и тесты

У каждого компонента есть собственные истории со значимыми вариантами,
состояниями, длинным содержимым и узким экраном. Приложение и Storybook используют
одну тему и Tailwind-сборку. Истории служат примерами API; автоматические проверки
поведения и их ограничения описаны в [стратегии тестирования](testing.md).

## Ограничения ширины

Wrapper поддерживает `maxWidth="game"` для игровой страницы и `maxWidth="board"`
для поля и статуса. Это конечные layout-токены, а не произвольные размеры.
Board использует общий `--container-board` (20.5rem), включающий видимую рамку.
BoardCell экспортирует тип CellContent для готовых снимков клеток.
