# PR №6: центр preview и возвращение подсказок

Поправки к задаче №06 в той же ветке `codex/feat/006-new-game-and-queue`,
база исправлений `7c71f016c9699579971beb8e4cb0099b9edb0801`.
Пользователь подтвердил: под управлением имеется в виду прежний список подсказок,
а не новые экранные кнопки. Фигура должна визуально стоять по центру мини-поля.

## Результат и границы

Занятые клетки центрируются по обеим осям внутри stencil. Фон остаётся сеткой
4×4; поверх размещены четыре BoardCell в исходной относительной геометрии.
Половинные шаги внутренней сетки дают точный центр для I и фигур шириной 3.
Нет округления к целой клетке, перемещения игрового spawn или изменения domain.

Вернулись шесть исходных пар клавиш и описаний. По умолчанию список показывается
при отсутствии shortcuts; action availability всё ещё разрешает start/restart.
Пауза нативно отключена, статус сообщает о ещё не реализованных возможностях.
Игровые обработчики клавиш в этих поправках не добавлены.

## Обсуждение до тестов

Первый агент `/root/preview_feedback_scenarios`, gpt-6-astra, high,
fork_turns none, прочитал спецификации и реальные исходники. До изменения первого
теста получено явное согласие агента и подтверждение ведущего.

Содержательные уточнения:

- Одного центра bounding box недостаточно: неправильная фигура, наложенные,
  маленькие или невидимые клетки тоже могли бы пройти. Согласованы реальные
  прямоугольники цветных детей, размер четверти content и отдельные буквальные
  позиции каждой клетки. Диагностические исходные координаты не служат visual oracle.
- Проверка только четырёх foreground не ловит старые цветные клетки под ними.
  Поэтому фон содержит ровно 16 empty без data-piece, а весь stencil — ровно
  четыре occupied и 20 cell-узлов. При null остаются 16 и 0.
- Старый неканонический рисунок по углам остаётся в интеграции. Для браузера
  согласован более полезный смещённый асимметричный рисунок с ненулевыми minima;
  он обнаруживает потерю нормализации, отражение и генерацию по kind.
- Проверять все виды при root-font 200% необязательно: выбраны O, I и custom
  при 320 px, с измеренным увеличением текста минимум 1.99. Все восемь рисунков
  проверяются при обычном шрифте на 320/768/1280 — ещё 24 случая.
- Обрезка проверяется по реальным клеткам и overflow-предкам; положительный
  bounding box сам по себе не означает, что пользователь видит весь блок.
- Подсказки проверяются шестью точными парами внутри реальных строк, не набором
  независимых глобальных строк. Доступность кнопок, Tab, клик по disabled Pause,
  notice и полный ready после reload сохранены.

Прежние интеграционные clear/update/immutable-input/atomic-rejection случаи
сохраняют исходные literal-матрицы через sourcePreviewRows; отдельно проверяются
фон и цветные клетки. В браузере source-атрибуты не подменяют измерение геометрии.

## Чувствительность и финальные проверки

| Временный дефект | Выбранный тест и фактический assertion failure |

| O прижат сверху | O/1280: вертикальная ошибка клетки 26 px вместо <1 |
| T прижат слева | T/1280: горизонтальная ошибка 13 px вместо <1 |
| Не вычитается исходный minX | SuppliedStencil/1280: размер клетки отличается на 24 px вместо <1 из-за неверного размещения |
| Снова передан shortcuts: [] | Production ready/1280: вместо шести пар получен пустой список |

а не ошибки сборки. Скрипт восстанавливал исходники в finally; manifest подтверждает
возврат к исправленной версии. Затем полностью пересобраны приложение и Storybook.

Первая диагностическая попытка имела неверный начальный якорь фильтра и не выбрала
ни одного теста. Она не засчитана как обнаружение дефекта; после исправления
фильтра выполнены четыре проверки выше. Сохранён initial-selection-error.log.

Финальный `npm run check` — exit 0: типы, lint, 36 интеграционных тестов,

относительно базы исправлений — успешно.

Ручной CUA-просмотр: возвращённый список в приложении на 320/1280, центрированная
O и нестандартный рисунок, NewGameOnly у controls и страницы на 320/768/1280.
В двух новых режимах по шесть подсказок, start/restart доступны, Pause отключена,
горизонтального переполнения нет. Локальные логи/материалы:
