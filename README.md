# Tetris OOP

Локальный тетрис на TypeScript с игровым ядром на ООП и интерфейсом в браузере.

Сейчас реализованы локальная сборка, шесть базовых UI-компонентов
и интерактивный пример библиотеки. Игровые блоки,
страница и бизнес-логика появятся в следующих задачах. На главной пока только
проверочный заголовок, библиотека компонентов доступна в Storybook.

## Локальный запуск

Нужны Node.js 24.15 или новее в ветке 24.x и npm 11. `.nvmrc` выбирает Node 24.
Минимальная patch-версия нужна jsdom, используемому в интеграционных тестах.

```sh
npm ci
npm run dev
```

Приложение: [127.0.0.1:5173](http://127.0.0.1:5173).
Для библиотеки компонентов запусти в другом терминале:

```sh
npm run storybook
```

Storybook: [127.0.0.1:6006](http://127.0.0.1:6006).
Оба сервера привязаны к loopback-интерфейсу. Остановка — `Ctrl+C`.

## Сборка и проверки

Один раз установи Chromium для e2e:

```sh
npx playwright install chromium
```

Полная проверка:

```sh
npm run check
```

Команда проверяет типы и lint, запускает DOM-интеграцию Vitest, собирает приложение
в `dist/` и Storybook в `storybook-static/`, затем запускает Playwright в Chromium. Для просмотра собранного приложения: `npm run preview`
и [127.0.0.1:4173](http://127.0.0.1:4173). CI выполняет `npm ci` и `npm run check`
для PR в `develop`/`main` и при обновлении этих веток. CI устанавливает Chromium
с системными зависимостями и сохраняет HTML-отчёт, trace и снимки при сбоях.

Отдельно: `npm run test:integration` и `npm run test:e2e`. Последняя команда
сначала собирает приложение и Storybook, затем сама поднимает их static preview
на `127.0.0.1:4180` и `127.0.0.1:6106`. Эти порты должны быть свободны; существующие
серверы не переиспользуются. Оба сервера останавливаются тестовым раннером.

Локальный HTML-отчёт: `npx playwright show-report`. Повторы отключены;
браузерные ошибки и неудачные загрузки ресурсов приводят к падению теста.
Охват, обсуждение сценариев и независимое ревью задачи №03 —
в [отчёте тестирования](docs/reviews/003-ui-foundations.md).
Игровая логика пока не реализована и этим набором не покрывается.

Стек: TypeScript в строгом режиме, Vite, Tailwind CSS, DOM-компоненты и Storybook;
Vitest для интеграционных и отдельных юнит-тестов, Playwright для e2e. Разработка
и запуск — в этой локальной папке; сервер игры и внешние сервисы не нужны.

UI строится от базовых компонентов к блокам и странице. Все собственные компоненты
и их истории лежат плоско в `/components` в корне проекта. Весь видимый текст
проходит через `Typography`, внешний layout — через `Wrapper`. При создании
и изменении каждого компонента, блока и страницы применяется навык `ui-refactoring`.

Каждая задача выполняется в отдельной ветке и завершается pull request в `develop`.
К следующей задаче переходим после ревью и принятия текущей пользователем.
Релиз в `main` проходит отдельным PR.
