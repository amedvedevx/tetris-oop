# Tetris OOP

Локальный тетрис на TypeScript с игровым ядром на ООП и интерфейсом в браузере.

Проект находится на этапе проектирования: исходного кода и команды запуска пока нет.
Настройка запуска — следующая задача после ревью проекта.

## Проект

- [Архитектура и границы классов](docs/architecture.md)
- [Правила первой версии](docs/game-rules.md)
- [Фичи, задачи и Git Flow](docs/roadmap.md)
- [Стратегия тестирования и независимого ревью](docs/testing.md)

Стек: TypeScript в строгом режиме, Vite, HTML/CSS, Vitest для интеграционных
и отдельных юнит-тестов, Playwright для e2e. Разработка и запуск — в этой локальной
папке; сервер игры и внешние сервисы не нужны.

Каждая задача выполняется в отдельной ветке и завершается pull request в `develop`.
К следующей задаче переходим после ревью и принятия текущей пользователем.
Релиз в `main` проходит отдельным PR.
